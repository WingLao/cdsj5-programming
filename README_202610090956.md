# CDSJ5 比賽與升學

公開網站：https://winglao.github.io/cdsj5-programming/
Repository：https://github.com/WingLao/cdsj5-programming （GitHub Pages 由 `main` 分支根目錄發布）

本資料夾是匯出工具產生的公開網站；不要直接修改，也不要上傳上層資料夾。

更新步驟：

1. 修改上層的來源檔或 `public/`，雙擊「匯出GitHub網站_202610090956.command」重新產生本資料夾。
2. 確認內容後，雙擊「部署GitHub網站_202610090956.command」推送到 GitHub，約一分鐘後網站更新。

本資料夾由雲端硬碟同步，所以不在這裡放 `.git`；部署指令會在暫存資料夾 clone、覆蓋、commit、push。

`index.html` 是 `index_202610090956.html` 的副本，供 GitHub Pages 作入口。
本機預覽：`python3 -m http.server 8770 --bind 127.0.0.1`，開啟 http://127.0.0.1:8770/ 。
本網站只供本班學生使用：每頁設有 noindex，要求搜尋引擎不收錄；資料檔以 Base64 存放，避免以姓名搜尋到。這不是存取限制，有連結的人仍可查看。
公開資料含比賽賽程、地點、官方連結，以及學生姓名、班級、參賽名單、獎項、入圍及晉級（榮譽榜）；不公開個人分數及未入圍紀錄；不含學號、准考證號、老師姓名、校內備註、附件、原始試算表及憑證。
「升學加分」分頁直接讀取獨立的升學加分指南網站（https://winglao.github.io/admissions/），本網站不另存指南。
